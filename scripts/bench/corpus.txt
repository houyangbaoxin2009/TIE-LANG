# tie 基准语料清单（自举 v2 计划 T0.1，冻结 101 个 .tie 文件）
#
# 格式：<路径> <pass|fail>
#   - 路径为相对仓库根的 POSIX 风格路径（如 examples/hello.tie）
#   - pass = 期望编译通过，参与耗时对比
#   - fail = 期望编译失败（如 oop_neg_* 负例），只记录退出码，不参与耗时对比
#   - '#' 开头的行为注释
#
# 生成方式（仓库根执行，排除 target/dist/archive/.git/.omo/compiler）：
#   Get-ChildItem -Recurse -Filter *.tie -File |
#     Where-Object { $_.FullName -notmatch '\\target\\|\\dist\\|\\archive\\|\\\.git\\|\\\.omo\\|\\compiler\\' }
#
# 注：compiler/ 为 tie 自举编译器新骨架，单独基准（self-compile），不混入 Rust-vs-tie 对比。
# 新文件加入时保持本清单按目录分组、字典序排列。
